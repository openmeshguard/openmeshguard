# OpenMeshGuard v0.1.0

OpenMeshGuard Community now turns an Istio cluster's configuration into resolved
per-workload security posture and evidence a platform or security engineer can
review. It covers sidecar and ambient mTLS, authorization attachment and waypoint
gaps, environment and ownership context, and Git-native exceptions.

Run a read-only scan, then consume canonical JSON, a single-file HTML report,
SARIF, or scores. Missing permissions and missing classification remain explicit
unknowns. CI failure thresholds are opt-in.

This release reports **declared and resolved posture**. It does not prove what
traffic happened on the wire: Prometheus collection and runtime controls
MG-MTLS-101/102 are the next milestone, M7. The report's Verified column states
that runtime evidence is unavailable.

Download a Linux or macOS archive for amd64 or arm64 from this release, or run:

```sh
go install github.com/openmeshguard/openmeshguard/cmd/openmeshguard@v0.1.0
openmeshguard version
openmeshguard scan --context my-cluster --all-namespaces > report.json
openmeshguard report --input report.json --format html --output report.html
```

Every binary archive and `checksums.txt` has its own `.sigstore.json` bundle.
Follow the [verification instructions](https://github.com/openmeshguard/openmeshguard/blob/v0.1.0/docs/releases/verification.md)
before running a downloaded binary. This v0 release remains an early version;
review its evidence gaps and validate conclusions against your environment.
