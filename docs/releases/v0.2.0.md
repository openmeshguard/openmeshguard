# OpenMeshGuard v0.2.0

OpenMeshGuard Community adds optional runtime verification from Prometheus.
The scanner names sidecar workloads that received observed plaintext traffic
within the selected window, while keeping their declared mTLS and authorization
posture separate.

`MG-MTLS-101` reports observed plaintext; declared strict plus observed plaintext
is always critical. `MG-MTLS-102` reports the mutual TLS share of observed HTTP
request and TCP connection-opening events. Missing evidence and no observed
traffic remain unknown control outcomes, never passes.

```sh
openmeshguard scan --namespace payments \
  --prometheus-url https://prometheus.example.com \
  --prometheus-token-file /path/to/token > report.json
openmeshguard report --input report.json --format html --output report.html
```

Bearer token files and mTLS client certificates are supported. Queries aggregate
only at destination workload granularity. Defaults are a seven-day lookback,
one-hour API step, and thirty-second query timeout; cost failures can reduce a
chunk's window to 24h with an explicit warning. Source attribution is omitted,
and ambient/mixed destination verification remains unknown pending validation.
Use a Prometheus endpoint scoped to the scanned cluster. See
[runtime semantics and limits](https://github.com/openmeshguard/openmeshguard/blob/v0.2.0/docs/telemetry/prometheus.md).

Without Prometheus, reports now include explicit runtime unknown/not-applicable
findings and related score unknown counts and permission evidence. Existing
configuration findings and declared posture are preserved. The canonical JSON
schema and existing exported resolver/output interfaces are unchanged.

Download signed Linux or macOS archives for amd64/arm64, install through the
Homebrew tap, or use Go:

```sh
brew install openmeshguard/tap/openmeshguard
# Alternatively:
go install github.com/openmeshguard/openmeshguard/cmd/openmeshguard@v0.2.0
```

Each archive and checksum file has a Sigstore bundle. Follow the
[verification instructions](https://github.com/openmeshguard/openmeshguard/blob/v0.2.0/docs/releases/verification.md)
before running downloaded binaries. This remains an early Community release;
verify telemetry coverage and policy changes when investigating a contradiction.
